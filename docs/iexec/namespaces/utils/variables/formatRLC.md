# Variable: formatRLC()

> `const` **formatRLC**: (`nRLC`) => `string`

format a nRLC amount in RLC

_NB_: units are not supported, the amount must be expressed in nRLC

example:
```js
console.log('500000000 nRLC =' + formatRLC('500000000') + 'RLC');
```
