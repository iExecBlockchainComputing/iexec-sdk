# Variable: formatEth()

> `const` **formatEth**: (`wei`) => `string`

format a wei amount in Eth

_NB_: units are not supported, the amount must be expressed in wei

example:
```js
console.log('500000000 wei =' + formatEth('500000000') + 'ether');
```
